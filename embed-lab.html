BitcornWisdom / Embed SDK

Two independent charts running inside iframes, controlled by a host application. Local demo mode uses explicitly synthetic candles. Remove demo=1 for real public exchange market feeds.

Every chart reports its active venue and reasons for failover. BTC/USD spot may switch between Kraken and Coinbase; instruments and quote currencies remain distinct. The client holds no trading keys and makes read-only data connections.

import { mountBitcornChart } from './src/embed-sdk.js';
const chart = mountBitcornChart('#my-chart', {
  instrument: 'BTC-USD-SPOT', interval: '1m', preferred: 'kraken'
});
chart.on('source', ({ source }) => console.log('Now using', source));
await chart.ready;
chart.setMarket('ETH-USD-SPOT', '5m');
